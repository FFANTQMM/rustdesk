# Название и иконка программы

Всё меняется здесь, в папке `branding/`, прямо на сайте GitHub. Потом запустите сборку:
**Actions → Build vepidesk → Run workflow**.

## Название: `branding.json`

```json
{
  "name": "RustDesk",
  "description": "RustDesk Remote Desktop"
}
```

| Поле | Где видно | Ограничения |
|---|---|---|
| `name` | заголовки окон, трей, ярлыки, имя службы, папка `C:\Program Files\<name>`, процесс `<name>.exe` | только латиница, цифры, `-` и `_`, без пробелов, до 32 символов |
| `description` | «Диспетчер задач» → вкладка «Процессы» | любой текст, можно по-русски |

Как поменять на сайте: откройте `branding.json` → значок карандаша → исправьте → **Commit changes**.

## Иконка: `icon.png`

Загрузите сюда файл **`icon.png`**: квадратный, от 256×256 (лучше 512×512), с прозрачным фоном.
При сборке из него сами сделаются иконка программы, ярлыка и трея.
Зелёный значок «идёт сессия» программа сделает сама (синий цвет станет зелёным).

Как загрузить: в папке `branding` → **Add file → Upload files** → перетащить `icon.png` → **Commit changes**.

## Логотип в окне (по желанию): `logo.png`

Картинка в главном окне программы, до 300×60. Загрузите как `logo.png`.

## Важно при смене названия

После смены `name` новая версия ставится **рядом** со старой (другая папка и служба).
Старую удалите: «Параметры → Приложения → RustDesk → Удалить», затем установите новую.
